# Support

## Getting Help with Convoca

### Documentation

- **User Manuals**: each plugin includes a `MANUAL_USUARIO.md` with step-by-step guides
- **Online Docs**: see [docs.getconvoca.app](https://docs.getconvoca.app) for installation and integration guides
- **API Reference**: inline PHPDoc blocks and REST API endpoints are self-documenting at `/wp-json/convoca/v1/`

### Community Support

- **GitHub Issues**: [github.com/josecarlosnieto91](https://github.com/josecarlosnieto91) — bug reports and feature requests
- **Discussions**: community forum at [getconvoca.app/community](https://getconvoca.app/community)

### Priority Support (PRO License)

PRO license holders receive priority support:

- **Email**: support@convoca.org
- **Response time**: within 24 hours (business days)
- **Scope**: installation, configuration, troubleshooting, and bug fixes
- **Exclusions**: custom development, third-party integrations, server administration

### Before You Submit a Request

1. **Check the manual** — most questions are answered in `MANUAL_USUARIO.md`
2. **Search existing issues** — your problem may already be solved
3. **Include details**:
   - Plugin name and version
   - WordPress version
   - PHP version
   - Steps to reproduce
   - Error messages (check WordPress debug log)
   - Screenshots if applicable

### Bug Reports vs Feature Requests

| Type | Where | Include |
|------|-------|---------|
| Bug report | GitHub Issues | Steps, expected vs actual behavior, environment |
| Feature request | GitHub Discussions | Use case, proposed solution |
| Security issue | security@convoca.org | See SECURITY.md — do NOT open public issues |
